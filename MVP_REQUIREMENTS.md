# Internet Rural México — MVP Requirements

**Status: LOCKED FOR MVP IMPLEMENTATION — 2026-09-08**

## Goal

Build the smallest useful website that turns rural connectivity problems into qualified Starlink referral opportunities through trustworthy education.

## MVP pages

1. Home
2. Internet Rural
3. Starlink México
4. ¿Starlink es para mí?
5. FAQ
6. Sobre nosotros
7. Divulgación
8. Privacidad
9. Contacto

## Qualification inputs

Property type, current connectivity, reliability problem, work/business dependence, video calls, cameras, streaming/gaming, users/devices, cellular coverage, budget sensitivity, and ability to install with sky visibility.

## Qualification outputs

- Buena opción para investigar
- Posible opción; revisa costos/alternativas
- Probablemente no es la mejor primera opción

Never guarantee availability, price, speed, uptime, or suitability.

## Architecture

Next.js/Vercel first. Existing Turborepo template is the technical foundation. Expo and FastAPI remain in the repo but are dormant for this MVP. Supabase is not required unless a concrete MVP requirement appears.

## Non-goals

No accounts, social network, CRM, AI chatbot, automated content generator, complex dashboard, payments, Stripe, large database, or automated social posting.

## Definition of done

Mobile-first, fast, accessible, SEO-ready, current Starlink facts sourced from official information, visible referral disclosure, no fabricated claims/testimonials, production build passes, and clear referral CTA.
